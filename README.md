# Azure Palace — 3D Study

A procedural, browser-based Three.js interpretation of the supplied seaside-hotel image. It builds the cream-colored coastal hotel, blue glass domes, balconies, palms, café terrace, promenade, beach, and sea from 3D geometry.

## Run

Open `index.html` in a modern browser with an internet connection. Three.js and OrbitControls are loaded from jsDelivr. Drag to orbit and use the mouse wheel to zoom.
